# M1 plugin

Free AU MIDI FX + VST3. Same chord engine as the box. Not started.

The music lives in [`../engine`](../engine). This folder is the DAW host: MIDI Learn, extra settings, and (when hardware is plugged in) an editor that **does not voice**.

Spec: [`../docs/goals.md`](../docs/goals.md) (plugin section) and [`../docs/chord-engine.md`](../docs/chord-engine.md).

Do not build a photoreal device GUI until the enclosure exists. Do not name modes after other products.
